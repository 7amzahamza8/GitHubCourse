GitHub & Git Commands Ranked

Ordered from the most vital day-to-day commands to advanced or rarely used operations.

Tier 1: Essential Daily Drivers

Most Important
git clone <url> Rank #1

Clones an existing remote repository down to your local machine.

git clone https://github.com/user/repo.git
git status Rank #2

Shows the state of your working directory and staging area (modified, untracked, staged files).

git status
git add <file> Rank #3

Adds file changes to the staging area, preparing them to be committed.

git add . (stages all changes)
git commit -m "message" Rank #4

Records a permanent snapshot of your staged changes with a descriptive message.

git commit -m "Fix login button alignment"
git push origin <branch> Rank #5

Uploads your local commits to the remote repository (e.g., GitHub).

git push origin main
git pull Rank #6

Fetches changes from the remote repository and immediately merges them into your current local branch.

git pull origin main

Tier 2: Branching & Collaboration

Very Important
git branch Rank #7

Lists all local branches, or creates a new one if specified.

git branch feature-login
git checkout <branch> (or git switch) Rank #8

Switches your active working environment to a different branch.

git checkout main
git merge <branch> Rank #9

Joins development histories together by merging a separate branch into your current branch.

git merge feature-login
git log Rank #10

Shows the chronological commit history for the current repository.

git log --oneline --graph
git diff Rank #11

Shows line-by-line differences between files in your working directory and staging area.

git diff

Tier 3: Setup & Management

Moderately Important
git init Rank #12

Initializes a brand new, empty Git repository in your local project folder.

git init
git remote add origin <url> Rank #13

Connects your local repository to a remote server link (like a GitHub repo URL).

git remote add origin https://github.com/user/repo.git
git stash Rank #14

Temporarily shelves uncommitted changes so you can work on something else, then pop them back later.

git stash pop
git fetch Rank #15

Downloads objects and refs from another repository without automatically merging them.

git fetch origin
git reset <file> Rank #16

Unstages changes or rolls back commits to a previous state.

git reset HEAD~1 (keeps code changes, drops commit)

Tier 4: Advanced & Troubleshooting

Less Common
git rebase <branch> Rank #17

Reapplies commits on top of another base tip, creating a linear history instead of merging.

git rebase main
git cherry-pick <commit-hash> Rank #18

Applies the changes introduced by an existing specific commit onto your current branch.

git cherry-pick a1b2c3d
git tag <tag-name> Rank #19

Creates a permanent marker (like v1.0.0) on a specific commit, often used for releases.

git tag -a v1.0 -m "Release version 1.0"
git clean -fd Rank #20

Deletes untracked files and directories from your working directory.

git clean -fd

Tier 5: Niche & Administrative

Rarely Used
git reflog Rank #21

Tracks every change to the tip of branches, acting as an ultimate safety net to recover lost commits.

git reflog
git submodule add <url> Rank #22

Allows you to keep a Git repository as a subdirectory of another Git repository.

git submodule add https://github.com/lib/plugin.git
git bisect Rank #23

Uses binary search to find the exact commit that introduced a bug into the codebase.

git bisect start; git bisect bad; git bisect good v1.0
git gc Rank #24

Cleans up unnecessary unreferenced files and optimizes the local repository database.

git gc --prune=now
